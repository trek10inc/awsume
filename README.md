# AWSume: AWS Assume Made Awesome

> **This project is no longer actively maintained.**
> AWSume served its purpose well, but the AWS CLI has matured to natively handle most of what AWSume was built for — including profile switching, credential management, and SSO support. We'd recommend migrating to the [AWS CLI](https://aws.amazon.com/cli/) for these workflows.
>
> The project will remain available here and on PyPI as-is. If you'd like to continue developing it, you're welcome to fork it. Thank you to everyone who used and contributed to AWSume over the years.

Check out the documentation at [awsu.me](https://awsu.me)!
